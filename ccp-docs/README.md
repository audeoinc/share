# CCP(Campaign Contents Planner)の共有用資料

配信(メール・アプリのプッシュ通知)の企画を、AI の提案を選びながら行う Web アプリ「Campaign Contents Planner(CCP)」について、
ユーザーストーリーなどの資料を作るための素材を置く場所。アプリの本体(ソースコード)は、ここにはない(非公開のリポジトリで管理している)。

| ファイル | 内容 |
|---|---|
| [USER_STORIES.md](USER_STORIES.md) | ユーザーストーリー(下書き)。カテゴリごとに、ユーザーストーリー・作業・確認を書いた。各行に、実装済み(✅)/ 一部(🟡)/ 未実装(⬜)の印と、番号(`1-作1` など)がある |
| [FEATURE_REASONS.md](FEATURE_REASONS.md) | 機能ごとの「理由の台帳」と、作業・確認との対応表。両方向のつながりの確認結果と、推測で書いた理由の一覧(要確認)もある |
| [wireframes/](wireframes/WIREFRAMES.md) | 画面構成(ワイヤーフレーム)。draw.io の図(`ccp-wireframes.drawio`。Confluence の draw.io マクロで取り込む)と、本文(`WIREFRAMES.md`)。英語版・US 向け。全 13 画面(カレンダー、配信カードの各工程、プッシュ、週のレビュー、週の比較、テンプレート管理、振り返り、アラート、一覧) |

- 内容は、**下書き**。実装の状況(✅ / 🟡 / ⬜)は、作成時点のもの。
- 書式(カテゴリ → ユーザーストーリー → 作業 → 確認)は、そのまま、他の資料の書式に当てはめて使える。
