# CCP(Campaign Contents Planner)の共有用資料

配信(メール・アプリのプッシュ通知)の企画を、AI の提案を選びながら行う Web アプリ「Campaign Contents Planner(CCP)」について、
ユーザーストーリーなどの資料を作るための素材を置く場所。アプリの本体(ソースコード)は、ここにはない(非公開のリポジトリで管理している)。

| ファイル | 内容 |
|---|---|
| [USER_STORIES.md](USER_STORIES.md) | ユーザーストーリー(下書き)。カテゴリごとに、ユーザーストーリー・作業・確認を書いた。各行に、実装済み(✅)/ 一部(🟡)/ 未実装(⬜)の印がある |

- 内容は、**下書き**。実装の状況(✅ / 🟡 / ⬜)は、作成時点のもの。
- 書式(カテゴリ → ユーザーストーリー → 作業 → 確認)は、そのまま、他の資料の書式に当てはめて使える。
