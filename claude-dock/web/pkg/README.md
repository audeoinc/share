# Claude Rogue 使い方ガイド

Claude Rogue は、**Claude Code をブラウザで使うための画面**です。Claude と会話しながら、ファイルを読ませたり、直させたり、変更を確認したりできます。

> 非公式です。Anthropic とは無関係の、個人が作ったツールです。

<!--light-->
> **ライト版**です。この PC にインストール済みの **Claude Code** を使います (Claude Code 本体は、この中に入っていません)。Claude Code (`claude.exe`) が入っていない PC では、起動時にメッセージが出て止まります。先に Claude Code をインストールしてください。
<!--/light-->

## 1. はじめる (3 ステップ)

### 必要なもの
| もの | 説明 |
|---|---|
| **Windows** | Windows 10 / 11 |
| **Node.js** | 入っていなければ、<https://nodejs.org/> から「LTS」をダウンロードして、インストールします (すべて「次へ」で構いません) |
| **インターネット** | 初回の準備と、Claude との会話に使います |
| **Claude の利用権限** | Claude にログイン済みの Claude Code か、API キーの設定が必要です (下の「2. Claude へのログイン」) |

### ステップ 1: 展開する
ZIP を、好きな場所に展開します (例: `C:\Users\あなた\crogue`)。展開すると、次の形になります。

```
crogue\
  start.cmd    ← これをダブルクリックします
  README.md    ← このファイル
  app\         ← 中身 (触らなくて構いません)
```

### ステップ 2: `start.cmd` をダブルクリックする
- 黒い画面 (コマンドプロンプト) が開きます。
- **初回だけ**、必要な部品のインストールが始まります。<!--full-->約 2〜3 分 (約 580MB)<!--/full--><!--light-->約 1〜2 分 (約 340MB)<!--/light-->かかるので、そのままお待ちください。
- 準備ができると、**ブラウザが自動で開いて**、Claude Rogue の画面が出ます。

> 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください (ダウンロードしたファイルには、よく出ます)。

### ステップ 3: 作業フォルダを選んで、話しかける
1. 画面の左上に、**作業フォルダ**のバーがあります。右の 📁 を押して、Claude に作業させたいフォルダを選びます。
2. 画面下の入力欄に、頼みたいことを書いて、**Enter** で送ります。
   例: 「このフォルダのファイルを一覧にして、それぞれ何をするものか教えて」

これで使い始められます。

### 終わるとき
黒い画面を**閉じる** (または `Ctrl+C`) と、終了します。ブラウザだけを閉じても、裏でサーバーは動いたままなので、黒い画面も閉じてください。次回からは、また `start.cmd` をダブルクリックするだけです (2 回目以降は、数秒で開きます)。

## 2. Claude へのログイン
Claude Rogue は、Claude Code と同じ認証を使います。次のどちらかで使えます。

- **Claude にログイン済み**の場合 (Pro / Max などの契約): その認証が、そのまま使われます。
- **API キー**を使う場合: `C:\Users\あなた\.claude\settings.json` に、次のように書きます。
  ```json
  { "env": { "ANTHROPIC_API_KEY": "sk-ant-..." } }
  ```
  (すでに `settings.json` があれば、`"env"` の部分だけ足してください。キーは、他人に見せないでください。)

「認証できません」などのエラーが出たら、上のどちらかを確認してください。

## 3. 画面の見かた

```
┌ 上のバー: [ドキュメント] [A−][A＋] [≡][◐]  モデル  effort  権限モード ┐
├ 左 ─────────┬ 中央 ───────────────┬ 右 ────────┤
│ 作業フォルダ │ 会話                  │ プレビュー  │
│ [会話]       │ (Claude とのやりとり) │ (ファイルの │
│ [ファイル]   │                       │  表示・編集) │
│ [実行][変更] ├───────────────────────┤             │
│ 一覧         │ 入力欄 [送信]         │             │
└──────────────┴───────────────────────┴─────────────┘
```

### 上のバー
| 項目 | はたらき |
|---|---|
| **ドキュメント** | 公式ドキュメントなどのリンク集です。クリックすると、新しいタブで開きます。「リンクを編集…」で、自分用のリンクも足せます |
| **A− / A＋** | 画面全体の文字の大きさ |
| **≡** | 行間 (詰める / 標準 / ゆったり) |
| **◐** | テーマ (自動 / ライト / ダーク) |
| **モデル** | 使う Claude のモデル。「既定」のままで構いません。軽くて速いのは Haiku、高性能なのは Opus |
| **effort** | 考える深さ。高いほど、深く考えますが、時間と費用が増えます。「既定」のままで構いません |
| **権限モード** | Claude がファイルを直したり、コマンドを実行したりするときの、確認のしかた (下の「許可の確認」) |

### 左のタブ
| タブ | 内容 |
|---|---|
| **会話** | これまでの会話の一覧です。クリックで、続きを開けます。検索欄で、題名・フォルダ・ブランチを絞り込めます |
| **ファイル** | 作業フォルダのファイルの一覧です。クリックで、右にプレビューが出ます |
| **変更** | Git の変更の一覧です。確認して、コミットできます |
| **実行** | コマンドを実行して、結果を見られます |

## 4. 基本の操作

### 話しかける
- 入力欄に書いて、**Enter** で送信します。改行は **Shift+Enter** です。
- Claude の返事は、少しずつ表示されます。途中で止めたいときは、**■ 停止** を押します。
- 「`/`」から始めると、使えるコマンド (スラッシュコマンド) の候補が出ます。

### 許可の確認
Claude がファイルを変更したり、コマンドを実行したりするときは、**確認が出ます**。内容を見て、選びます。
- **許可**: 今回だけ許可します。
- **このセッションでは常に許可**: 同じ種類の操作を、この会話の間は、確認なしにします。
- **拒否**: やめさせます。

「権限モード」を変えると、確認の量を調整できます。迷ったら、「確認しながら進める」のままにしてください。

### 応答中に、追加で頼む
Claude が作業しているあいだも、入力欄に書いて、**待機に追加** (または Enter) を押せます。入力欄の上に「待機中」の帯が出ます。
- **今すぐ送信**: 作業は止めずに、追加の依頼を取り込ませます (Claude が次の区切りで読んで、そのまま続けます)。
- **止めて送信**: いまの作業を止めて、新しい依頼として送ります。
- **取り消し**: 入力欄に戻します。

### ファイルやフォルダを渡す
- 左のファイル一覧から、入力欄 (会話の欄) へ**ドラッグ**します。ファイルも、フォルダもできます。
- パソコンのファイルも、入力欄へドラッグするか、📎 を押して選べます (画像の貼り付け Ctrl+V も使えます)。
- フォルダを渡すと、Claude が、その中のファイルを必要なだけ読みます。

### ファイルを見る・直す
1. 左の「ファイル」で、ファイルをクリックすると、右にプレビューが出ます (Markdown は整形されて、Mermaid の図も出ます。画像・PDF・PowerPoint も見られます)。
2. 右上の **✎ 編集** を押すと、その場で書き換えられます。**Ctrl+S** で保存します。
3. 保存前の変更があるうちは、題名に ● が付きます。ほかのファイルを開くときは、保存するか確認が出ます。

### Git (変更の確認とコミット)
- 左の「変更」タブに、変更されたファイルが出ます。クリックすると、右に差分が出ます (「並べて表示」で、左右の比較もできます)。
- 下の欄にメッセージを書いて、コミットできます。「✨ 提案」で、Claude にメッセージの案を作らせることもできます。
- ブランチは、左上のバーのブランチ名から切り替えられます。
- **会話を開いたとき、その会話のブランチと、いまのブランチが違うと、確認や警告が出ます。** 違うブランチのファイルを、うっかり直さないための仕組みです。

### コマンドを実行する
- 左の「**実行**」タブに、コマンド (例: `npm test`) を入れて、Enter で実行します。結果は、その場で流れます。
- 会話の入力欄で、**`!` から始めて** (例: `!dir`) Enter を押しても、同じように実行されます。
- 結果は「Claude に渡す」で、入力欄に入れて、「このエラーを直して」と頼めます。

### 会話の履歴
- 「会話」タブで、過去の会話を選ぶと、その会話の**フォルダとブランチ**に、戻って続きを開きます。
- 一覧の行にカーソルを置くと、名前の変更 (✎) と、削除 (🗑) が出ます。**削除は元に戻せません。**

## 5. 困ったとき

| 症状 | 対処 |
|---|---|
| ブラウザが開かない | 黒い画面に出ている `http://127.0.0.1:…/?t=…` の URL を、ブラウザのアドレス欄に貼り付けます |
| 「Node.js が見つかりません」と出る | Node.js をインストールして、もう一度 `start.cmd` をダブルクリックします |
| 初回のインストールが終わらない・失敗する | ネットワークの接続を確認します。会社のプロキシが原因のことがあります。IT 担当の方に確認してください |
| 「ポート 8787 は使用中です」と出る | すでに起動している画面があります。次の空きポートで、自動で起動するので、そのまま使えます。**黒い画面に出た新しい URL を使ってください** |
| 画面がおかしい・古い | ブラウザで **Ctrl+F5** (強制的に読み込み直し) を押します |
| Claude から返事がない | 認証 (上の「2. Claude へのログイン」) を確認します。「停止」を押して、もう一度送ってみてください |
<!--light-->
| 「Claude Code (claude.exe) が見つかりません」と出る | Claude Code をインストールしてください。入っているのに見つからないときは、環境変数 `CDOCK_CLAUDE_PATH` に `claude.exe` のパスを指定します |
| 「…バージョンと違います」と出る | Claude Code のバージョンが、この画面の想定 (2.1.293) と違います。使えますが、古いと一部の機能が動かないことがあります。Claude Code を更新してください |
<!--/light-->

### 新しい版に更新するには
新しい ZIP を、別の場所に展開して、そちらの `start.cmd` を使います (初回の準備が、もう一度走ります)。会話の履歴や、リンクの設定は、PC に保存されているので、そのまま引き継がれます。

## 6. 知っておいてほしいこと
- **Claude は、あなたの代わりに、ファイルを変更し、コマンドを実行できます。** 許可の確認は、内容を見てから押してください。大事なフォルダでは、先に Git で、変更を記録しておくと安心です。
- この画面は、**あなたの PC の中だけ**で動きます (外部には公開されません)。起動時の URL の `?t=…` は、あなた専用の合言葉です。他人に渡さないでください。
- Claude の利用には、契約の枠や、API の利用料がかかります。各回答の下に、**費用の目安**が出ます。
- 作業フォルダに指定したフォルダの中を、Claude は読み書きします。広すぎるフォルダ (ホームフォルダ全体など) は、おすすめしません。

より詳しい説明 (設定、環境変数、開発者向けの情報) は、`app\README.md` にあります。
