# Claude Rogue 使い方ガイド

Claude Rogue は、**Claude Code をブラウザで使うための画面**です。Claude と会話しながら、ファイルを読ませたり、直させたり、変更を確認したりできます。

---

## 前提
- **Windows** の PC であること
- **Node.js** が使える状態であること
- **Claude Code** が使える状態であること (PC の `claude.exe` を、この画面が使います)
- API キーを含む **`settings.json`** の設定が済んでいること

---

## 1. はじめる

```
crogue\
  start.cmd    ← これをダブルクリックします
  README.md    ← このファイル
  app\         ← 中身 (触らなくて構いません)
```

1. ZIP を、好きな場所に展開します。
2. **`start.cmd` をダブルクリック**します。黒い画面が開きます。
   - **初回だけ**、必要な部品のインストールが走ります (約 1〜2 分)。そのままお待ちください。
   - 準備ができると、**ブラウザが自動で開いて**、画面が出ます。
   - 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
3. 左上の**作業フォルダ**のバーで、📁 を押して、Claude に作業させたいフォルダを選びます。
4. 画面下の入力欄に、頼みたいことを書いて、**Enter** で送ります。

※ ブラウザを開きたくないときは、**Shift キーを押しながらダブルクリック**します (黒い画面に「Shift key detected」と出るまで、押し続けてください)。コマンドラインからは `start.cmd --no-open` です。

### 終わるとき
黒い画面を**閉じる** (または `Ctrl+C`) と、終了します。ブラウザだけ閉じても、裏でサーバーは動いたままなので、黒い画面も閉じてください。2 回目からは、`start.cmd` をダブルクリックするだけで、数秒で開きます。

## 2. 画面の見かた

```
┌ 上のバー: [ドキュメント] [A−][A＋] [≡][◐]  モデル  effort  権限モード ┐
├ 左 ─────────┬ 中央 ───────────────┬ 右 ────────┤
│ 作業フォルダ │ 会話                  │ プレビュー  │
│ [会話]       │ (Claude とのやりとり) │ (ファイルの │
│ [ファイル]   │                       │  表示・編集) │
│ [実行][変更] ├───────────────────────┤             │
│ 一覧         │ 入力欄 [送信]         │             │
└──────────────┴───────────────────────┴─────────────┘
```

| 上のバー | はたらき |
|---|---|
| **ドキュメント** | 公式ドキュメントなどのリンク集です。「リンクを編集…」で、自分用のリンクも足せます |
| **A− / A＋ / ≡ / ◐** | 文字の大きさ / 行間 / テーマ (自動・ライト・ダーク) |
| **モデル / effort** | 使う Claude のモデルと、考える深さです。「既定」のままで構いません |
| **権限モード** | ファイルの変更やコマンド実行の、確認のしかたです (下の「許可の確認」) |

| 左のタブ | 内容 |
|---|---|
| **会話** | これまでの会話の一覧です。クリックで、続きを開けます。検索欄で、題名・フォルダ・ブランチを絞り込めます |
| **ファイル** | 作業フォルダのファイルの一覧です。クリックで、右にプレビューが出ます |
| **変更** | Git の変更の一覧です。確認して、コミットできます |
| **実行** | コマンドを実行して、結果を見られます |

## 3. 基本の操作

**話しかける**: 入力欄に書いて **Enter** で送信、改行は **Shift+Enter** です。途中で止めたいときは **■ 停止** を押します。「`/`」から始めると、スラッシュコマンドの候補が出ます。

**許可の確認**: Claude がファイルを変更したり、コマンドを実行したりするときは、確認が出ます。
- **許可**: 今回だけ。 **このセッションでは常に許可**: 同じ種類の操作を、この会話の間は確認なしに。 **拒否**: やめさせます。
- 「権限モード」で、確認の量を調整できます。迷ったら「確認しながら進める」のままに。

**応答中に、追加で頼む**: 作業中でも、入力欄に書いて「**待機に追加**」(または Enter) を押せます。入力欄の上に出る帯で選びます。
- **今すぐ送信**: 作業は止めずに、追加の依頼を取り込ませます。 **止めて送信**: いまの作業を止めて、新しい依頼として送ります。 **取り消し**: 入力欄に戻します。

**ファイルやフォルダを渡す**: 左のファイル一覧から、入力欄 (会話の欄) へ**ドラッグ**します (フォルダも可。中身は Claude が必要なだけ読みます)。PC のファイルは、入力欄へドラッグするか、📎 を押して選びます (画像の貼り付け Ctrl+V も可)。

**ファイルを見る・直す**: 「ファイル」でクリックすると、右にプレビューが出ます (Markdown は整形され、Mermaid の図も出ます。画像・PDF・PowerPoint も見られます)。右上の **✎ 編集** で書き換えて、**Ctrl+S** で保存します。

**Git**: 「変更」タブに、変更されたファイルが出ます。クリックで差分 (「並べて表示」で左右の比較も)、下の欄でコミットできます (「✨ 提案」で、メッセージの案を作らせられます)。ブランチは、左上のバーのブランチ名から切り替えます。
- 会話とブランチの関係は、下の「会話とブランチ」を見てください。

**コマンドの実行**: 「実行」タブにコマンド (例: `npm test`) を入れて Enter。会話の入力欄で、`!` から始めて (例: `!dir`) Enter でも同じです。結果は「Claude に渡す」で、入力欄に入れて「このエラーを直して」と頼めます。

**会話の履歴**: 「会話」タブで選ぶと、その会話の**フォルダとブランチ**に戻って、続きを開きます。行にカーソルを置くと、名前の変更 (✎) と削除 (🗑) が出ます (**削除は元に戻せません**)。

---

## 会話とブランチ (Git のフォルダで使うとき)
- 会話は、そのときの**フォルダ**と**ブランチ**に結びついています。
- 会話を開くと、その会話のフォルダに移ります。ブランチが違えば「切り替えますか？」と確認が出ます (切り替えて開くのがお勧めです)。
- **コミットしていない変更が残っていると、ブランチは切り替えられません。** コミットなどで片付けると、切り替えられます。
- 開いたあとも、会話のブランチといまのブランチが違うあいだは、会話の上に**黄色の帯**が出ます。違うブランチのまま続けると、**いまのブランチのファイルが変更されます**。
- 迷ったら、作業を始める前に、左上のバーで、いまのブランチを確かめてください。

## 4. 困ったとき

| 症状 | 対処 |
|---|---|
| ブラウザが開かない | 黒い画面に出ている `http://127.0.0.1:…/?t=…` の URL を、ブラウザのアドレス欄に貼り付けます |
| 「Node.js が見つかりません」と出る | Node.js が使える状態か確認して、もう一度 `start.cmd` をダブルクリックします |
| 初回のインストールが終わらない・失敗する | ネットワークの接続を確認します (会社のプロキシが原因のことがあります) |
| 「Claude Code (claude.exe) が見つかりません」と出る | 黒い画面の `claude --version` で、Claude Code が使えるか確認します。入っているのに見つからないときは、環境変数 `CDOCK_CLAUDE_PATH` に `claude.exe` のパスを指定します |
| 「…バージョンと違います」と出る | Claude Code のバージョンが、この画面の想定 (2.1.293) と違います。使えますが、一部の機能が動かないことがあります |
| 「ポート 8787 は使用中です」と出る | すでに起動している画面があります。次の空きポートで自動で起動するので、**黒い画面に出た新しい URL を使ってください** |
| 画面がおかしい・古い | ブラウザで **Ctrl+F5** を押します |
| Claude から返事がない | 「停止」を押して、もう一度送ります。続くときは、黒い画面で `claude` を実行して、Claude Code 自体が動くか確認します |

**新しい版に更新するには**: 新しい ZIP を別の場所に展開して、そちらの `start.cmd` を使います (初回の準備が、もう一度走ります)。会話の履歴やリンクの設定は、PC に保存されているので、引き継がれます。

## 5. 知っておいてほしいこと
- **Claude は、あなたの代わりに、ファイルを変更し、コマンドを実行できます。** 許可の確認は、内容を見てから押してください。大事なフォルダでは、先に Git で変更を記録しておくと安心です。
- この画面は、**あなたの PC の中だけ**で動きます。起動時の URL の `?t=…` は、あなた専用の合言葉なので、他人に渡さないでください。
- 各回答の下に、**費用の目安**が出ます。
- 広すぎるフォルダ (ホームフォルダ全体など) を、作業フォルダにするのは、おすすめしません。

より詳しい説明 (設定、環境変数、開発者向けの情報) は、`app\README.md` にあります。
