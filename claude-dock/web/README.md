# cdock web

Claude Code をブラウザで使うローカル UI。Claude Agent SDK で Claude Code と同じエージェント(ファイル操作・コマンド実行・権限確認)を動かし、
Code タブ風の画面で操作します。ターミナル版の `cdock` (tmux / Windows Terminal) とは独立です。

## 位置づけ

**Claude Code のための、会話とレビューの作業台。** Claude と話し、Claude が変えたものを見て (プレビュー・差分)、
小さな修正や文書の手直しはその場で行う、というところまでを受け持ちます。IDE の代わりではありません。

**やらないこと (非目標)**: 言語サーバーによる補完・型チェック、デバッガー、ターミナルエミュレーション、拡張機能。
編集は Monaco ですが、補完・ホバー・エラー波線などは意図して切っています。本格的な開発は VS Code などで行い、並べて使う想定です。

## 使い方
```
cd claude-dock\web
start.cmd [作業フォルダ]        # 初回は npm install も実行。表示された URL をブラウザで開く
```
URL には起動ごとのトークン (`?t=...`) が付きます。`127.0.0.1` のみで待ち受け、他の PC / 他サイトからは接続できません。

ファイルの読み取り (プレビュー・ツリー) は、指定した作業フォルダの中に限定しています (外へのパスやシンボリックリンクは拒否)。

認証は Claude Code と同じ (`/login` 済み、または `ANTHROPIC_API_KEY`)。`~/.claude/settings.json` の `env` に API キーを入れている場合も
`settingSources: ['user','project','local']` で読み込まれる想定です (実環境で要確認)。

## 今できること (段階 1〜4)
- 会話 (ストリーミング表示 / Markdown / コード)、ツール実行のカード表示 (入力と結果の折りたたみ)
- 権限確認 (許可 / このセッションでは常に許可 / 拒否)、権限モード切替 (確認 / 編集自動許可 / プラン / 自動)
- 停止ボタン、作業フォルダ指定、所要時間・費用の目安・トークン内訳の表示
- 進行中の表示: 会話の最後に、動くスピナーと状態 (考え中 / 準備中 / 実行中 + ツール名と内容 / 許可の確認待ち / サブエージェント実行中 / 会話の要約中)、経過秒数を表示。クリックで実行中のコマンドの全文を展開
- 左サイドバー「会話」: フォルダごとの過去の会話一覧、クリックで再開 (履歴とツール結果も復元)、「新しい会話」
- 左サイドバー「ファイル」: ツリー表示 (フォルダは遅延読み込み)。クリックで右側にプレビュー、`＠` ボタン / ダブルクリック / ドラッグで入力欄に `@パス` を挿入
  - **自動更新**: 作業フォルダを監視し、ファイルの作成・移動・削除 (ターミナルや他のアプリでの操作、Claude が作ったファイルも) を、開いているフォルダと Git の一覧・検索・プレビューに反映 (開いたフォルダとスクロール位置は保持)。
    「↻」ボタンの手動更新と、ウィンドウに戻ったときの更新もあります。ホームやドライブ直下など広すぎるフォルダでは監視を止めます
  - **ドラッグで移動**: ファイル・フォルダを別のフォルダ (または空いている場所 = 最上位) へドラッグ。移動のたびに「元に戻す」付きのお知らせを表示。
    移動先に同名があるときは **「両方残す (名前を変えて移動: `a (2).txt`)」「置き換える (元のものはごみ箱へ)」「キャンセル」** を選べます (元に戻すと、改名も置き換えも元通り)。
    作業フォルダの外・`.git` の中・フォルダ自身の中へは移動できません。ファイルを会話欄へドロップすると、移動ではなく添付になります
  - **削除 (cdock のごみ箱へ)**: 行を選んで **Delete キー**、または右クリック「ごみ箱へ移動…」。確認ダイアログ (既定はキャンセル) → ごみ箱へ移動し、「元に戻す」付きのお知らせ。
    ごみ箱は `%USERPROFILE%\.cdock-trash\` に 30 日間保管 (OS のごみ箱ではありません)。「ファイル」タブの 🗑 で一覧 → **復元 / 完全に削除 / ごみ箱を空にする**
    (復元先に同名があれば名前を変えて戻します。削除できるのは作業フォルダの中だけで、`.git` や作業フォルダ自身は不可)
  - 右クリックメニュー: プレビュー / ＠ 入力欄に挿入 / 添付する / パスをコピー / ごみ箱へ移動
- ファイル検索 (「ファイル」タブ上部、Ctrl+P): 名前のあいまい検索 (複数語可、.gitignore を尊重) と、「中身」切り替えでの全文検索 (行番号つき。
  クリックで該当行を強調してプレビュー)。↑↓ で選択、Enter で開く、Shift+Enter で `@パス` を挿入
- **場所のバー** (サイドバーの一番上。会話・ファイル・変更のすべての前提になる「作業フォルダ」と Git の情報をまとめたもの):
  - **パンくず**: パスの各部分をクリックして、そのフォルダを作業フォルダにします。現在の場所、または空いている所をクリックすると、パスを直接入力できます (Enter で確定 / Esc で取り消し。存在しないパスは赤く表示して送信を止めます)。長いパスは左側を薄く隠して、現在の場所が見えるようにします
  - **↑ ボタン** (Alt+↑): 一つ上のフォルダへ移動 (昔の Windows エクスプローラーと同じ。ツールチップに移動先を表示)
  - **📁**: フォルダ選択の画面 (ホーム / ドライブ / 最近使った / 絞り込み / 隠しフォルダ)。**Git のリポジトリには 🔀 の印とブランチ名**を表示し、「リポジトリだけ表示」で絞れます。行の「選ぶ」で、そのフォルダを作業フォルダにして閉じます。存在しないパスを指していたら、いちばん近いフォルダを開きます
  - **Git のチップ** (リポジトリの中にいるときだけ): `⎇ ブランチ名 ●(未コミットの変更あり)`。作業フォルダがリポジトリの中のサブフォルダなら、`リポジトリ名 · ⎇ ブランチ名`。押すと、どのタブにいてもブランチの切り替え・新規作成のメニューが開きます
  - ツリーのフォルダを右クリック →「**このフォルダを作業フォルダにする**」
  - 作業フォルダを変えると会話の画面は、そのフォルダの会話に切り替わります (会話はフォルダごと)
  - 狭い画面では、サイドバーが上に積まれて、同じ操作ができます
- テーマ: 上部の ◐ で 自動 (OS に従う) / ☀ ライト / ☾ ダーク を切り替え (記憶されます)
- プレビュー: テキスト・コード (UTF-8 / Shift_JIS 自動判別)、Markdown (見出し・表・引用・入れ子の箇条書き・タスクリスト・画像・相対リンクに対応。「ソース」で原文に切り替え)、画像 (png/jpg/gif/webp/svg)、PDF (ブラウザのビューア)、
  PowerPoint (.pptx) は **スライド画像** (PowerPoint が入っている Windows のみ。裏で読み取り専用・マクロ無効で開いて PNG に書き出し、`%TEMP%\cdock-slides\` にキャッシュ。すでに開いている PowerPoint は閉じません) とテキストの切り替え、Word (.docx) は中身のテキスト (図・書式は表示されません)
- スラッシュコマンド: 入力欄で `/` を打つと候補 (組み込み + スキル + カスタム、説明つき) が出ます。↑↓ で選び、Tab / Enter で挿入。
  `/compact` (会話の要約)、`/context` (使用状況の表)、`/clear` (新しい会話) など
- 会話の名前変更: 一覧の ✎ から。Claude Code 本体の会話履歴にも反映されます
- 左サイドバー「変更」: Git の変更を「ステージ済み / 変更 / 未追跡 / 競合」に区分して一覧 (ブランチ名・件数バッジ)。クリックで HEAD との差分を右側に表示。
  行の ＋/− でステージ・解除、「すべてステージ / すべて解除」、下のコミット欄でコミット (Ctrl+Enter)。応答のたびに自動更新。
  ブランチ名のボタンから、**ブランチの切り替え / 新規作成** (ローカル、リモートだけのブランチは追跡ブランチを作成。未コミットの変更が衝突するときは Git が拒否してその文言を表示)。
  コミット欄の **「✨ 提案」** で、ステージ済みの差分と最近の件名 (書き方の参考) を Claude (Haiku) に送ってメッセージ案を作成 (ツールなし・会話履歴に残さない。内容は確認・編集してからコミット)。
  Git の書き込みは **ステージ・解除・コミット・ブランチの切り替え/作成のみ** (破棄・push・ブランチ操作はありません)。フック (pre-commit など) は通常どおり実行されます
- **編集** (テキスト・Markdown のプレビュー右上の「✎ 編集」): Monaco エディタで開き、Ctrl+S で保存。小さな修正向け (上限 2MB、バイナリ・.git 内は不可)。
  - 保存は一時ファイル経由の置き換え。元の文字コード (UTF-8 / BOM あり / Shift_JIS) と改行 (LF / CRLF) を保ちます。Shift_JIS で表せない文字を入れたときは、確認のうえ UTF-8 に変換できます
  - 未保存の変更は、タイトルの ● で分かります。ほかのファイルを開く・閉じる・フォルダを変える・ページを閉じるときは、保存 / 破棄 / キャンセルを確認します
  - 開いたあとに外部 (Claude や他のツール) がファイルを変えたら、バナーで知らせます。保存時に食い違っていれば、上書き / 外部の内容を読み込む / キャンセルを選べます
  - テーマ・文字サイズは画面全体に追従。エディタ本体 (約 5MB) は初めて編集するときだけ読み込みます
- Git の差分は「並べて表示」(右上のボタン) で、HEAD と作業ツリーを Monaco の差分エディタで比べられます (読み取り専用。記憶されます)

- **実行** (サイドバーの「実行」タブ): コマンドを作業フォルダで1回ずつ実行し、出力 (標準出力・標準エラー) を流しながら表示します。`npm test` や `npm run build` など、入力を求めないコマンド向け。
  - シェルは Windows では **Windows PowerShell が既定**。コマンド欄の左の選択で cmd にも切り替えられます (記憶されます)。環境変数 `CDOCK_WEB_SHELL=cmd` で既定を cmd に、`CDOCK_WEB_SHELL=pwsh` で PowerShell 7 に変えられます。PowerShell の起動は遅いので、「実行」タブを開いたときに 1 つ先に起動しておき、1 回ごとに使い捨てます (標準入力は閉じています)。Windows PowerShell 5.1 は `&&` が使えません (`;` で続けてください)
  - 停止ボタン、所要時間、成功 / 失敗 (終了コード) の表示。↑↓ で履歴 (30 件)
  - 会話の入力欄で `!コマンド` と打って Enter でも実行できます (Claude には送らず、「実行」タブに切り替えて実行。Claude の応答中でも可)
  - 「Claude に渡す」で、コマンドと出力の末尾 200 行を、会話の入力欄にコードブロックとして入れます
  - 標準入力は閉じています。`npm init` / `npm login` のように入力待ちになるコマンドや、vim などは非対応です (本物のターミナルで実行してください)。ターミナルエミュレーションではありません
  - 色などの制御文字は取り除き、進捗の書き換え (
) は最後の行だけ残します。出力の上限は 8MB (超えると停止)

- 差分表示: Edit / MultiEdit / Write のツールカードに、変更前 (赤) と変更後 (緑) を表示
- ペイン幅の変更: サイドバーとプレビューの境界をドラッグ (←→ キーでも可、ダブルクリックで初期値)。幅は記憶され、会話欄は常に 340px 以上を確保
- 行間・余白: 上部の ≡ で 詰める / 標準 / ゆったり を切り替え (既定は標準。記憶されます)
- ファイルの添付 (入力欄の上にチップで表示。×で外せる):
  - エクスプローラー等から **ドラッグ＆ドロップ** / Ctrl+V で貼り付け (スクリーンショット) / 📎 ボタン。1 件 50MB まで、20 件まで。フォルダは不可
  - 左のエクスプローラ・検索結果から **ドラッグ＆ドロップ** (プロジェクト内のファイル。アップロード不要)
  - サーバーが古くて添付に未対応のときは、送信前に「サーバーを再起動してください」と表示。読み込めなかった添付があるときも画面に通知します
  - OS からのファイルは `%TEMP%\cdock-uploads\` に保存 (7 日で自動削除。作業フォルダは汚しません)。Claude は Read ツールで画像・PDF・テキストを読みます。
    添付はプロンプト末尾の `<attachments>` ブロックで伝え、履歴を開くとチップに戻して表示します
- モデル選択: SDK が返す実際の一覧 (Opus / Fable / Sonnet / Haiku ほか)。「既定 → Sonnet 5.5」のように既定が何になるかを表示し、会話が始まると実際に使われたモデル名で更新
- 文字サイズ (画面全体): 既定 14px。上部の A− / A＋ で 12〜20px。会話・差分・サイドバー・ツリー・プレビュー・ダイアログのすべてが連動 (ダブルクリックで初期値、記憶される)
- フォントは OS 既定 (`system-ui`)、コードは IBM Plex Mono (入っていれば)。追加のフォント配布は不要
- モデル選択 (Opus 5.5 / Sonnet 5.5 / Haiku 4.5 / 既定)

### 費用についての注意
画面の費用は SDK が出す「API 従量課金だった場合の目安」で、Max プランのログインでは請求されません (プランの使用量には数えられます)。
新しい会話ごとに Claude Code の標準指示・ツール定義などで約 36k トークンがキャッシュに書き込まれます。キャッシュはモデルごとなので、
**会話の途中でモデルを切り替えると履歴全体が書き直され**、費用が増えます。切り替えるなら新しい会話で。

## 予定
.ppt / .docx のページ画像、ブランチの削除・マージ、リモートへの push など

## 開発用
`node test-md.mjs` で Markdown 変換の単体テスト (XSS 対策の確認を含む)。
`CDOCK_WEB_MOCK=1 node server.js` で認証なしの模擬応答 (画面の動作確認用)。ポートは `--port` / `CDOCK_WEB_PORT`、トークン固定は `CDOCK_WEB_TOKEN`。
