Confluence 貼り付け検証チェックリスト

  • 各サンプルの <table>…</table> を HTML マクロに貼り、追加=緑・削除=赤・変更のハイライトが色付きで残るか
  • もし背景色が消えても、左端の色付きボーダーと + / − マーカーで差分が判別できるか（背景ストリップ対策）

  • 3ペインが横並びのまま崩れず、横スクロールで収まるか
  • 角丸・罫線・余白の「ミニマル Cool」トーンが再現されるか
