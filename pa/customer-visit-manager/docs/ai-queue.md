# AI 呼び出しの仕組み(サービスアカウント方式)

外部ゲストでも AI の下書きが使えるように、アプリは Copilot Studio を**直接呼ばず**、Dataverse の「airequest」テーブルを仲介にする。
AI の呼び出しは、Power Automate のフロー(フローの持ち主の接続)が行う。ゲストは、Copilot Studio の接続もライセンスも不要で、Dataverse の権限だけで足りる。

```
アプリ ──(1) 依頼の行を追加──▶ airequest テーブル ──(2) 行が追加されたとき──▶ フロー ──▶ Copilot Studio のエージェント
  ▲                                   ▲                                       │
  └────(4) 返答を読み取り、行を削除────┴────────(3) 返答を行に書き戻す──────────┘
```

## 1. Dataverse のテーブル「airequest」

| 項目 | 値 |
|---|---|
| 表示名 | airequest |
| スキーマ名 | `cr854_airequest`(論理名は、小文字になる) |
| 所有者 | ユーザーまたはチーム(既定) |

| 列の表示名 | スキーマ名(プレフィックスを除いた部分) | 種類 | 備考 |
|---|---|---|---|
| name(主列) | `name` | 単一行テキスト | アプリが `req-日時` を入れる |
| prompt | `prompt` | 複数行テキスト | 最大文字数は 100000。AI への依頼文(ルール + 入力データ) |
| response | `response` | 複数行テキスト | 最大文字数は 100000。エージェントの返答 |
| status | `status` | 選択肢 | 値は、この順で: **待機中** / **完了** / **エラー**。既定値は「待機中」 |

## 2. Power Automate のフロー「AI要求の処理」

作成する場所: [Power Automate](https://make.powerautomate.com/) で、環境を `katada_dev` にする。
接続は、AI を呼ぶ権限のあるアカウント(あなた、または専用のサービス用アカウント)でサインインして作る。

1. **新しいフロー → 自動化したクラウド フロー**。名前は「AI要求の処理」。
2. **トリガー:** Microsoft Dataverse の「**行が追加、変更、または削除されたとき**」
   - 種類の変更: **作成**
   - テーブル名: **airequest**
   - スコープ: **組織**(ゲストが作った行にも反応させるため)
3. **アクション 1:** Microsoft Copilot Studio の「**Execute Agent and wait**」
   - Agent: 配信企画エージェント(`new_cr854_deliveryagent`)
   - Message: 動的コンテンツの **prompt**
4. **アクション 2:** Microsoft Dataverse の「**行を更新する**」
   - テーブル名: airequest
   - 行 ID: トリガーの「airequest」(行の ID)
   - response: アクション 1 の **Last response**(最後の応答)
   - status: **完了**
5. **失敗したときの処理:** もう 1 つ「行を更新する」を追加する。
   - 「実行条件の構成」で、アクション 1 が「**失敗した**」「**タイムアウトした**」にチェックを入れる(「成功した」は外す)。
   - 行 ID: 上と同じ。status: **エラー**。response: `エージェントの呼び出しに失敗しました`
6. 保存して、**オン**にする。

## 3. セキュリティロール(ゲスト用)

ロール「配信コンテンツプランナー利用者」に、テーブル「airequest」の権限を足す。
範囲は、**ユーザー**(自分が作った行だけ)でよい。

| 作成 | 読み取り | 書き込み | 削除 |
|---|---|---|---|
| ユーザー | ユーザー | ユーザー | ユーザー |

フローは、ゲストが作った行を更新するが、行の所有者はゲストのままなので、ゲストは返答を読み取れる。

## 4. アプリ側の動作

- `src/aiSelect.ts` の `askAgent` が、依頼の行を作り、2 秒ごとに状態を確認する(最大 3 分)。
- 状態が「完了」なら返答を読み取り、「エラー」ならエラーにする。どちらでも、読み取ったあとに、行を削除する。
- アプリの接続は Dataverse だけになる。Copilot Studio の接続は、アプリから外す(`pa app remove data-source`)。
