# Multi File Diff（社内用 VS Code 拡張機能）

エクスプローラーで **2 つまたは 3 つのファイルを選択して右クリック**すると、
その差分を比較できます。3 ファイル同時比較は VS Code 標準にはない機能です。

見た目・配色は VS Code 標準の差分エディタに合わせてあり、
色はすべてテーマ変数（`--vscode-*`）から取っているので、
ライト / ダーク / ハイコントラストのどのテーマでも自然に馴染みます。

## 使い方

1. エクスプローラーで Ctrl（Mac は Cmd）を押しながらファイルを 2〜3 個選択
2. 右クリック → メニューから選ぶ

| メニュー | 動作 |
| --- | --- |
| 選択したファイルを比較 | 2 ファイル → VS Code 標準の差分エディタ / 3 ファイル → 並列ビュー |
| 選択したファイルを比較 (並列ビュー) | ファイル数によらずこの拡張機能の並列ビューで開く |
| 選択したファイルを比較 (標準の差分エディタ) | 標準の差分エディタで開く。3 ファイルなら「1↔2」「2↔3」を左右に 2 枚並べる |

選択した順番がそのまま左からの並び順になります。

## 並列ビューの機能

- **1 番目のファイルが基準**。基準と内容が一致する列は赤系、異なる列は緑系で表示します
  （＝どのファイル同士が同じ内容かがひと目で分かる）。対応する行が無い箇所は斜線塗り。
- 変更された行は **単語単位**で変わった部分だけを濃く強調します。
- 一致している行が続く区間は折りたたまれます（前後 3 行は残す）。クリックで展開。
- ツールバー
  - `↑` `↓` … 前 / 次の差分へ移動（`F7` / `Shift+F7`、`Alt+↑` / `Alt+↓` も可）
  - `変更箇所のみ` … 一致区間の折りたたみ ON/OFF
  - `折り返し` … 長い行の折り返し ON/OFF
  - `空白を無視` … 行頭・行末の空白だけの違いを無視
  - `大小文字を無視` … 大文字・小文字の違いを無視
  - `更新` … ファイルを読み直す
  - `HTML 出力` … 比較結果を単体で開ける HTML として保存する（下記）
- 行番号をクリックすると、そのファイルの該当行をエディタで開きます。
- 右端のバーは差分の位置を示します。クリックでその位置へジャンプ。
- 比較中のファイルを保存すると自動で再計算されます。編集中（未保存）の内容も反映されます。

### 制限

並列ビューは Webview で描画しているため、**構文ハイライトは付きません**。
構文ハイライト付きで見たい場合は「標準の差分エディタ」のメニューを使ってください
（3 ファイルなら 2 枚の差分エディタが左右に並びます）。

## HTML 出力とプレビュー

並列ビューの `HTML 出力` を押すと、保存先を聞かれたあと、
**その比較結果を単体で開ける HTML ファイル**として書き出し、
続けて VS Code 内の Webview でプレビューを開きます
（`multiFileDiff.openPreviewAfterExport` で自動プレビューは切れます）。

出力される HTML の特徴：

- CSS / JavaScript / 行データをすべて 1 ファイルに埋め込むので、**外部ファイルを一切参照しません**。
  メールや Slack でそのまま渡せますし、ブラウザにドラッグしても開けます。
- **出力した時点の VS Code テーマの色をそのまま焼き込む**ので、
  拡張機能の入っていない環境で開いても同じ配色になります。
- 折りたたみの展開、`変更箇所のみ` / `折り返し` の切り替え、`F7` での差分ジャンプは
  出力後の HTML でもそのまま動きます。
  拡張機能が無いと働かないボタン（`更新`・`空白を無視`・`大小文字を無視`・`HTML 出力`）は
  自動的に隠れます。

任意の HTML ファイルは、エクスプローラーで右クリック →
`HTML を Webview でプレビュー` でも表示できます（保存すると自動で再読み込み）。
相対パスの `src` / `href` は webview URI に読み替えるので、
同じフォルダーに置いた CSS や画像も表示されます。

## 設定

`設定` → `拡張機能` → `Multi File Diff`、または `settings.json`：

| 設定キー | 既定値 | 説明 |
| --- | --- | --- |
| `multiFileDiff.twoFileMode` | `native` | 2 ファイル選択時に使うビュー（`native` / `panel`） |
| `multiFileDiff.ignoreTrimWhitespace` | `true` | 行頭・行末の空白の違いを無視 |
| `multiFileDiff.ignoreCase` | `false` | 大文字・小文字の違いを無視 |
| `multiFileDiff.collapseUnchanged` | `true` | 一致区間を折りたたむ |
| `multiFileDiff.contextLines` | `3` | 折りたたみ時に残す前後の行数 |
| `multiFileDiff.wordWrap` | `false` | 長い行を折り返す |
| `multiFileDiff.openPreviewAfterExport` | `true` | HTML 出力の直後にプレビューを開く |
| `multiFileDiff.maxFileSizeKB` | `4096` | 比較を許可するファイルサイズ上限 (KB) |

## インストール（社内配布）

公開はしないので、次のどちらかで配ります。

### A. .vsix を作って配る（おすすめ）

```powershell
cd vscode-multi-file-diff
npm run package          # multi-file-diff-0.2.0.vsix ができる
```

受け取った側は次のどちらかでインストールします。

```powershell
code --install-extension multi-file-diff-0.2.0.vsix
```

または VS Code の拡張機能ビュー右上の `…` → `VSIX からのインストール…` で選択。

### B. フォルダーごとコピーする

ビルド不要（素の JavaScript）なので、このフォルダーをそのまま置くだけでも動きます。

```powershell
Copy-Item -Recurse vscode-multi-file-diff "$env:USERPROFILE\.vscode\extensions\multi-file-diff-0.2.0"
```

VS Code を再起動すれば有効になります（macOS / Linux は `~/.vscode/extensions/`）。

## 開発

- 依存パッケージなし・ビルド不要。このフォルダーを VS Code で開いて `F5` で
  「拡張機能ホスト」が起動し、その中で動作確認できます。
- 差分ロジックのテスト：

```powershell
npm test
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `extension.js` | コマンド登録、ファイル読み込み、Webview パネル / プレビューの生成、HTML 出力 |
| `src/diff.js` | Myers 法の差分アルゴリズム（依存なしの自前実装） |
| `src/align.js` | 2〜3 ファイルの行の突き合わせと、単語単位の強調 |
| `src/html.js` | パネル用 HTML と、単体で開ける出力用 HTML の組み立て |
| `media/main.css` | 差分エディタ風のスタイル（色はすべてテーマ変数） |
| `media/main.js` | Webview 側の描画と操作（パネル / 出力 HTML の両方で動く） |
| `test/smoke.js` | 差分ロジックのテスト |
